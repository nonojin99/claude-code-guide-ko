# Claude Code 슬래시(/) 명령 가이드

Claude Code를 이제 막 시작한 동료를 위한 한국어 참고 자료입니다.
`/`로 시작하는 명령을 **언제 쓰는지** 기준으로 묶었고, 처음 써볼 것부터 순서대로 정리했습니다.

- 웹페이지로 보기: https://nonojin99.github.io/claude-code-guide-ko/
- 기준: Claude Code 공식 문서 [Commands](https://code.claude.com/docs/en/commands) (2026-11 확인). 버전에 따라 명령이 바뀔 수 있으니 터미널에서 `/` 를 눌러 실제 목록을 확인하세요.

| 1 | [처음 시작하기](docs/01-getting-started.md) | 아직 설치만 했거나 대화만 해본 분 |
| 2 | [작업 단계별 명령](docs/02-commands-by-stage.md) | 매일 쓰는데 `/` 메뉴는 잘 안 여는 분 |

## 한 장 요약 (치트시트)

**처음 한 번**
- `/init` — 프로젝트 설명서 `CLAUDE.md` 초안 만들기
- `/memory` — `CLAUDE.md` 고치기
- `/permissions` — 어떤 명령을 묻지 않고 실행할지 규칙 정하기

**작업 중**
- `/plan 할 일` — 큰 변경 전에 계획부터 세우게 하기
- `/goal 조건` — 조건을 만족할 때까지 여러 턴에 걸쳐 계속 작업하게 하기
- `/btw 질문` — 대화 기록에 남기지 않는 곁가지 질문
- `/context` · `/compact` — 대화가 길어지면 확인하고 요약해서 비우기
- `/model` · `/effort` — 모델과 추론 강도 바꾸기

**끝내기 전**
- `/diff` — 바뀐 내용 보기
- `/code-review` — 버그 찾기 (`--fix` 를 붙이면 고치기까지)
- `/simplify` — 군더더기 정리

**문제가 생기면**
- `/rewind` — 코드와 대화를 이전 시점으로 되돌리기
- `/doctor` — 설치·설정 점검
- `/clear` — 새 작업은 새 대화로

**익숙해지면**
- `/insights` — 내 사용 패턴 리포트와 써볼 기능 추천
- `/hooks` · `/skills` · `/agents` — 자동화 장치 확인
- `/loop` · `/schedule` — 반복·예약 실행

## 먼저 알아둘 것

- 명령은 **메시지 맨 앞**에서만 인식됩니다. 명령 뒤에 쓴 글은 그 명령의 인자가 됩니다.
- `/` 만 누르면 쓸 수 있는 명령 목록이 뜨고, 글자를 더 치면 걸러집니다.
- Claude가 답하는 도중에 명령을 보내면 대기열에 들어갔다가 그 턴이 끝난 뒤 실행됩니다.
- 회사 PC·사내망에서 쓸 때는 반입·외부 연결 정책을 먼저 확인하세요.
