# 3. CLAUDE.md와 스킬

둘 다 "Claude에게 미리 알려주는 글"이지만 쓰임이 다릅니다.

| | CLAUDE.md | 스킬 |
|---|---|---|
| 언제 읽나 | 그 폴더에서 **항상** | 필요할 때만(이름을 부르거나 Claude가 판단) |
| 무엇을 적나 | 프로젝트 공통 규칙·구조 | 특정 작업 하나의 절차 |
| 예 | "원본 폴더는 수정 금지" | "주간 보고서 만드는 순서" |

## 스킬 만들기

`.claude/skills/<이름>/SKILL.md`(이 프로젝트) 또는 `~/.claude/skills/<이름>/SKILL.md`(내 모든 프로젝트)에 파일을 두면 `/이름` 명령이 생깁니다.

```markdown
---
name: weekly-report
description: 주간 설비 현황 보고서 초안을 만든다
---
1. data/ 폴더에서 이번 주 파일을 읽는다
2. 설비별 가동률·알람 건수를 표로 정리한다
3. 지난주 대비 변화가 큰 3건을 맨 위에 쓴다
4. output/ 에 날짜를 붙여 저장한다
```

이제 `/weekly-report` 라고만 치면 위 절차대로 일합니다. 뒤에 글을 붙이면 인자로 전달됩니다.

## 잘 쓰는 요령

- **같은 설명을 세 번 했다면** 스킬로 만들 때입니다.
- `description` 은 "언제 쓰는지"가 드러나게 씁니다. Claude가 스스로 꺼내 쓸지 판단하는 근거입니다.
- 스킬이 많아지면 `/skills` 에서 정리하세요. 안 쓰는 스킬도 목록에 올라가 있으면 대화 공간을 조금씩 차지합니다.
- 서브에이전트(`.claude/agents/`)는 별도 대화 공간에서 일하는 전문 조수입니다. 검토처럼 **작성자와 분리돼야 하는 일**에 좋습니다.
