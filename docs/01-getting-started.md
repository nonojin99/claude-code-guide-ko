# 1. 처음 시작하기

처음에는 명령 세 개만 쓰면 됩니다. **`/init` → `/memory` → `/permissions`** 순서입니다.

## `/init` — 프로젝트 설명서 만들기

작업 폴더에서 `/init` 을 실행하면 Claude가 폴더를 훑어보고 `CLAUDE.md` 초안을 씁니다.
`CLAUDE.md` 는 그 폴더에서 Claude가 **매번 자동으로 읽는 설명서**입니다. 폴더 구조, 실행 방법, 지켜야 할 규칙을 적어 둡니다.

> 예: "데이터 원본 폴더는 읽기만 한다", "결과 파일은 output/ 에 날짜를 붙여 저장한다"

## `/memory` — 설명서 다듬기

`CLAUDE.md` 를 열어 고칩니다. 같은 지적을 두 번 하게 되면 그 내용을 여기에 적어 두세요. 다음 대화부터는 말하지 않아도 지킵니다.

## `/permissions` — 확인 절차 줄이기

Claude는 파일을 고치거나 명령을 실행하기 전에 매번 허락을 구합니다. 자주 쓰는 안전한 명령(예: 테스트 실행)은 허용 목록에, 위험한 명령은 거부 목록에 넣어 두면 흐름이 끊기지 않습니다.

## 그 밖에 알아두면 좋은 기본 명령

| 명령 | 하는 일 |
|---|---|
| `/help` | 도움말과 쓸 수 있는 명령 보기 |
| `/model` | 모델 바꾸기(기본값으로 저장됨) |
| `/effort` | 추론 강도 조절(`low` ~ `max`, `auto`) |
| `/status` | 버전·모델·계정·연결 상태 보기 |
| `/usage` | 사용량과 플랜 한도 보기 |
| `/terminal-setup` | 줄바꿈용 Shift+Enter 단축키 설치(일부 터미널) |
| `/config` | 테마·모델 등 설정 화면 열기 |

## 첫 주 추천 연습

1. 자주 하는 일 하나(엑셀 정리, 보고서 초안 등)를 골라 폴더를 만든다
2. `/init` 으로 `CLAUDE.md` 를 만들고, 직접 3줄 이상 규칙을 보탠다
3. 같은 일을 세 번 시켜 보고, 세 번 다 지적한 점을 `CLAUDE.md` 에 옮긴다
